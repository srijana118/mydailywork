# Quiz Game (Python)

This project is a console-based Quiz Game developed using Python as part of my internship work.  
The application presents multiple-choice questions, evaluates user answers, provides instant feedback, calculates the final score, and displays the result along with percentage.

## Features
- Multiple-choice questions with four options (A/B/C/D)
- Questions loaded from an external JSON file
- Randomized question order for each quiz attempt
- Input validation for user responses
- Instant feedback for correct and incorrect answers
- Final score and percentage calculation
- Option to replay the quiz

## How to Run
1. Ensure Python 3.x is installed on your system
2. Open a terminal or command prompt
3. Navigate to the project directory
4. Run the following command:
   python quiz.py

## Rules
- Each question has four options: A, B, C, D
- Each correct answer carries 1 mark
- There is no negative marking
- Final result is displayed as score and percentage
