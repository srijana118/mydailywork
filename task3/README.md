# Quiz Game

This project is a console-based Quiz Game developed using Python.  
The game asks multiple-choice questions, evaluates user answers, calculates the final score, and displays the result along with percentage.

## Features
- Multiple-choice questions (A/B/C/D)
- Questions loaded from an external JSON file
- Input validation for user answers
- Instant feedback for correct and incorrect answers
- Final score and percentage calculation
- Option to replay the quiz

## Files Included
- quiz.py — Main Python program
- questions.json — Stores quiz questions and answers
- README.md — Project documentation
